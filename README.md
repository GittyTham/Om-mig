# Om mig

Min om mig sida som jag byggt under kursen på Chas Academy.

## Vad finns på sidan

Info om mig, mina skills, intressen, ett kontaktformulär och en tidslinje över vad jag gjort innan och nu.

## Interaktioner

- Mörkt läge, knapp uppe i menyn. Sidan kommer ihåg vad man valde.
- Flikar för Om mig, Skills, Intressen och Kontakt. Går att byta med piltangenterna också.
- Läs mer knapp som visar mer text och byter till Visa mindre.
- Texten "Jag är..." skriver sig själv med olika ord med hjälp av typewriter funktion.
- Tidslinjen tonar in när man skrollar ner.
- Kontaktformuläret säger till om man inte fyllt i allt. Formuläret skickar inte vidare något.

## Tillgänglighet

- Man kan använda sidan med bara tangentbordet och ser var man är med hjälp av en "fokusram".
- Skärmläsare får veta vilken flik som är vald och om Läs mer är öppen eller stängd.
- Skärmläsare hör hela meningen "Jag är UX-student, kodare och designer" istället för skrivmaskinen.
- Tidslinjen animeras inte om man har valt mindre rörelse i datorn.
- Alt-text på bilderna.
- Funkar på mobil telefon.
